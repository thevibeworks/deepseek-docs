# The full DeepSeek App experience, now via API

Search, files, links, safety, and voice. The capabilities behind the DeepSeek App are now available through the DeepSeek API.
Enable built-in features with a few parameters, or call standalone APIs such as OCR, ASR, and TTS. Build richer conversations or recreate the full DeepSeek App in your own application.

Try our open-source frontend demo, with support for importing DeepSeek conversation history.

🔗 Demo: <https://cdn.deepseek.com/chat-demo>

📦 Code: <https://github.com/deepseek-ai/chat-demo>

📖 Details: <https://api-docs.deepseek.com/guides/build_a_chatbot>

## 🛠️ Built-in tools. Flexible APIs.

V4.1-Flash (`deepseek-flash`) now supports these capabilities across `Messages`, `Responses`, and `Chat Completions`, with tool calls and context assembly handled server-side:

🔹 Web Search: Search the web or images with citations in non-thinking mode.

🔹 Deep Thinking Search: Search and read pages throughout multi-step reasoning.

🔹 File Input: Parse PDFs, Office files, images, and more into conversation context.

🔹 URL Reading: Automatically fetch links in user messages to inform answers.

🔹 Safety Checks: Screen inputs and outputs, returning refusal indicators when risks are detected.

Enable search with `deepseek_web_search` and URL reading with `deepseek_read_url`. Public-facing apps must enable safety checks. Developers remain responsible for content moderation, applicable model registration, and AI-generated content labeling.

Search, Fetch, OCR, ASR, and TTS are also available as standalone APIs for custom workflows.
